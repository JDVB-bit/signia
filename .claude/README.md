# 📘 `.claude/` — Reglas, plan y seguimiento del proyecto

Documentos que guían el desarrollo (también el que hace el asistente de IA).

| Archivo | Para qué sirve |
|---|---|
| `claude.md` | 🧭 Reglas fundamentales: rol de desarrollador principal, SOLID, Clean Architecture, visión de producto |
| `rules.md` | 📏 Reglas de código: buenas prácticas, README por directorio, comentarios, sin números mágicos, commits atómicos |
| `plan-implementacion.md` | 🗺️ Plan por fases (0 → 8) del modelo, el backend y el traductor |
| `mejoras.md` | ✅ Lista viva de lo hecho, lo pendiente y las ideas futuras |
| `launch.json` | ▶️ Cómo arrancar el servidor de desarrollo del front desde el editor |

## 🔄 Cómo se usan

1. Antes de programar: leer `claude.md`, `rules.md` y la fase actual del plan.
2. Al terminar una sesión: anotar lo hecho y lo pendiente en `mejoras.md`.
