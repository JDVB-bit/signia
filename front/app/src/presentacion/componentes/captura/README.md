# 🎯 `captura/` — Indicadores de Entrenamiento

| Archivo | Qué muestra |
|---|---|
| `IndicadorDeManos.jsx` | "sin manos" / "1 mano" / "2 manos" sobre el vídeo |
| `IndicadorDeGrabacion.jsx` | Punto rojo pulsante + segundos grabando |
| `ContadorDeMuestras.jsx` | Número de muestras tomadas en la sesión |

```jsx
<IndicadorDeManos cantidad={2} />
<IndicadorDeGrabacion segundos={1.4} />
<ContadorDeMuestras cantidad={12} />
```
