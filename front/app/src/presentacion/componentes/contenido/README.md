# 📰 `contenido/` — Bloques de contenido de Inicio

| Archivo | Qué es |
|---|---|
| `SectionCard.jsx` | Tarjeta con título para una sección |
| `InfoBubble.jsx` | Botón ⓘ que abre un diálogo con el detalle (cierra con ✕, Escape o clic fuera) |
| `Typewriter.jsx` | Texto que se escribe carácter a carácter |
| `ImageBelt.jsx` | Carrusel que empuja cada imagen hacia la izquierda en bucle continuo |
| `CarouselImage.jsx` | Una imagen del carrusel |

```jsx
<SectionCard title="Misión">
  <Typewriter text="Acercar la LSE a cualquier persona..." />
  <InfoBubble label="Más sobre nuestra misión"><p>Detalle...</p></InfoBubble>
</SectionCard>
```
